# pramok

PRAMOK Art Academy — Official Web Platform

Modern, responsive web application for Pramok Art Academy built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- **Hero & Student Artworks Showcase**: Smooth animated hero with graphite pencil realism gallery.
- **Courses Catalog**: Structured programs (Beginner, Advanced, Masterclass) with interactive filter tabs.
- **Course Detail & Curriculum**: Syllabus breakdown, video preview, instructor bio, and tuition pricing.
- **Student Enrollment**: Complete registration with Razorpay checkout integration mockup.
- **Student Dashboard**: Track learning progress, lesson history, and certificates.
- **Admin Portal**: Filterable enrollments dashboard with custom animated dropdowns and metrics.
- **Adaptive Navbar**: Real-time scroll spy with sliding Framer Motion indicator and dynamic hero-to-white color switching.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom CSS
- **Animations**: Framer Motion
- **Icons**: React Icons (Heroicons, FontAwesome)
- **Routing**: React Router v7

## Getting Started
```bash
npm install
npm run dev
```
